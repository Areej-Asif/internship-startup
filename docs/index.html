Content Refresh Opportunity Scoring Using Search Signals

Abstract

This research investigates how search performance signals can identify content pages with refresh opportunities. Using the FlyRank ML Internship dataset, this project analyzes content age, impressions, CTR, and ranking signals. A baseline scoring system was compared with a machine learning approach. The final system creates ranked recommendations to support content review decisions.

Problem Statement

Content teams have many pages but limited resources. This project supports the decision: Which pages should be reviewed and refreshed first?

Data

Dataset features:

  • impressions_90d
  • clicks_90d
  • ctr
  • avg_position
  • content_age_days

Excluded: private information, URLs, client details, and future-window data.

Methodology

A baseline rule-based score was created first. A Random Forest model was then trained using historical search signals to generate refresh opportunity scores.

Results

The model and baseline were compared using ranking evaluation approaches. The model provides a learned prioritization system while the baseline uses manual weighting.

Limitations

This system provides decision-support only. Observed relationships do not prove that refreshing content will directly increase traffic.

Reproducibility

All notebooks and experiments are available in the repository.
